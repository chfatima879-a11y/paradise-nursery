# Paradise Nursery Shopping Application

An e-commerce web application built with React and Redux Toolkit for an online plant shop called Paradise Nursery.

## Features
- **Landing Page:** Features company background and a "Get Started" call-to-action button.
- **Product Catalog:** Organizes houseplants into multiple categories with thumbnail images, names, descriptions, and prices.
- **Interactive Shopping Cart:** Powered by Redux Toolkit to add items, update quantities, delete products, and calculate total costs dynamically.
- **Navigation Bar:** Accessible across product and cart pages with dynamic item counters.
